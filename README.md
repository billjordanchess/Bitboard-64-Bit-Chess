# Bitboard-64-Bit-Chess
This is a 64-bit version of BitBoard Chess with added features. 

My book <i>How to Write a 64-Bit Chess Engine: Faster and Deeper</i> is based on this project. 
There are ebook and paperback versions. https://www.amazon.com.au/How-Write-64-Bit-Chess-Engine-ebook/dp/B0HC9R5BHS

Google <i>amazon billjordanchess</i> to see my other books on chess programming. 

MS Visual Studio will need to be installed.
Create a new folder where you want to extract the project.
Select the Code Button and select <b>Download zip</b>.
Extract the zip file into the new folder.
Open the solution file.
Build and Run
